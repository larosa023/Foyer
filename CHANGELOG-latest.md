## Foyer 0.2.0

### New
- **Settings window** — General, Appearance, Layout, Apps, Updates and About pages. Changes apply instantly, with a live preview of the menu.
- **Built-in updater** — checks GitHub Releases, verifies every download with SHA-256, installs with one click (or automatically), and rolls back by itself if a new version fails to start. Stable and Beta channels. Never interrupts games or fullscreen video.
- **Themes** — Follow Windows, Dark, Light, Midnight (pure black), Glass, Ember and Ocean, plus an accent color picker.
- **Acrylic and Mica** backgrounds with adjustable tint, and adjustable corner radius.
- **Layouts** — Modern (pinned grid + All apps), Classic (single column) and Full screen (launcher overlay). Choose position, density and icon size.
- **Motion** — slide-in open, staggered tiles, smooth hover fades, press feedback, smooth scrolling and tooltips. Turn it down to Fast or None any time.
- **Greeting** with your name and today's date, and a soft accent glow.
- **Backup and restore** of all settings to one file.

### How to update from 0.1.0
0.1.0 has no updater yet: quit Foyer from the tray, then run this Foyer.exe. From 0.2.0 on, updates install themselves.
